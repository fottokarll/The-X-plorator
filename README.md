# THE X-PLORATOR 🚀

**Project 0 City space exploration & civilisation-building game**  
Status: **Pre-production v0.1** — not yet playable or published.

Humanity flees a devastated Earth. As pilot of an evacuation ship, explore beautiful procedural star systems, mine resources, upgrade modular spacecraft, build hexagonal orbital bases, connect automated colonies, and work toward the **Genesis Initiative**: a sustainable new home for humanity.

## Development priorities

1. **M1 — Visual & Flight Prototype:** True 3D, six-axis arcade flight, three procedural planets, atmospheric lighting, asteroids, seven-tile hex base and mobile controls.
2. **M2 — Mining & Upgrades:** resource loop, hold capacity, ship components.
3. **M3 — Base Building:** hex modules and starter planet.
4. **M4 — Multiplayer & Saves:** official Project 0 SDK integration after verified docs.
5. **M5+ — Colony Logistics, Genesis, Fleet, ATT trading:** only after secure persistence and ownership are demonstrated.

## Art direction
Painterly low-poly space poetry: midnight navy, teal, coral, rose and gold. Original shader gradients, code-generated meshes, soft light and tranquil ambient piano. No stock art or imported PNG/3D model dependencies in the initial visual prototype.
