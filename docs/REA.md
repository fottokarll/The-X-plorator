REA official repository: https://github.com/morluto/rea . Setup may be prepared immediately, and the focused movement study begins **with the first steerable prototype**. See `codex/TASK_REA_001.md`.

**Target is movement feel, not graphic copying.** The ship should glide gracefully in blue-violet space, with adjustable acceleration, momentum, drag, banking, damping, boost response and smooth follow-camera lag. Underwater movement games such as ABZÛ are inspiration for observed motion; never reuse their protected code, assets, art, shaders or music. Do not claim numerical original game parameters without reproducible, authorized evidence.

Start with gameplay observation and open-source/authorized movement source before considering analysis of any proprietary executable; obtain necessary authorization and respect terms, do not bypass DRM or share binaries. REA local MCP setup requires compatible Node and a supported local agent; a Cloud Codex session does not automatically have REA or locally installed game files.

Technical steps and acceptance in `codex/TASK_REA_001.md`. REA must not block building the first beautiful playable sector or PC/mobile input. The output is an evidence-labelled flight-feel matrix plus two independent, testable controller profiles, for human selection.
